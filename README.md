
🛒 E-Commerce Analysis – Excel Dashboard

📊 Project Overview

This project focuses on analyzing **e-commerce data using Microsoft Excel** to understand customer behavior, order patterns, and product performance.
The dashboard helps identify **order trends, category-wise performance, revenue distribution, and key business insights** to support data-driven decision-making.

---

🗂 Data Source

* **File Name:** `Ecommerce_Client_Data.xlsx`
* **Data Type:** Sample e-commerce dataset
* **Data Preparation:**

  * Data cleaning and preprocessing performed in **Microsoft Excel**
  * Handled missing values and duplicates
  * Standardized date, currency, and category fields
* **Details:**
  The dataset includes information such as:

  * Order ID
  * Product Category
  * Quantity
  * Price / Revenue
  * Order Status
  * Location / Locality
  * Order Date

---

⚡ Key Insights

📦 **Order trends over time** (monthly / yearly analysis)
💰 **Revenue contribution** by product category
🏆 **Top-performing products and categories**
📍 **Location-wise order and revenue distribution**
❌ **Order status analysis** (Completed, Cancelled, etc.)
📊 **KPIs** to support e-commerce business decisions

---

🛠 Tools & Techniques

* **Microsoft Excel**
* Pivot Tables for summarization
* Pivot Charts (Bar, Line, Area)
* COUNTIFS & SUMIFS for conditional analysis
* Sorting & Filtering
* Slicers for interactive dashboards
* Conditional Formatting
* Excel dashboard design best practices

---

▶️ How to Open

1. Download the Excel dashboard file:
   **`Ecommerce_Analysis_Dashboard.xlsx`**
2. Open the file using **Microsoft Excel (2016 or later recommended)**.
3. Enable editing if prompted.
4. Use slicers and filters to interact with the dashboard and explore insights.
